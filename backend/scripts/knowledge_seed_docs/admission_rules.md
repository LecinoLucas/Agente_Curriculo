# Regras de Pré-Admissão

Estas regras definem o processo de pré-admissão para novos colaboradores.

## Checklist de Admissão
O checklist de admissão deve estar 100% completo antes de qualquer tentativa de exportação para o ERP.
Os documentos obrigatórios incluem:
- Documento de Identidade (RG ou CNH)
- CPF
- Comprovante de Residência
- Título de Eleitor
- Certificado de Reservista (para homens)
- Comprovante de Escolaridade

## Validação de Documentos
Documentos rejeitados precisam de correção imediata pelo candidato. O RH deve revisar cada documento enviado.
Um caso só pode avançar para a etapa de "Pronto para Admissão" quando todos os documentos forem validados e o status do checklist permitir.

## Exportação ERP
A exportação para o ERP Protheus exige uma validação final dos dados cadastrais. Se houver divergência entre os documentos enviados e os dados digitados, a exportação falhará.
A exportação real só ocorre se a flag de integração estiver ativa no sistema.
