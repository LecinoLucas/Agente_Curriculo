# Política de Uso do Assistente IA

Diretrizes para o uso correto e seguro do Assistente IA interno.

## Natureza do Assistente
O assistente opera em modo **somente leitura** (read-only). Ele não tem permissão para alterar dados, mover candidatos ou disparar e-mails.
Ele serve para consulta de informações e auxílio na análise de dados existentes.

## Fontes de Informação
As respostas do assistente baseiam-se exclusivamente nas fontes disponíveis na base de conhecimento e nos dados contextuais da página aberta.
Se não houver evidência documental para uma resposta, o assistente deve informar sua limitação em vez de alucinar informações.

## Segurança e Privacidade
Os usuários não devem inserir dados sensíveis (como credenciais de acesso ou dados pessoais de terceiros) nos campos de consulta.
O sistema filtra automaticamente termos sensíveis e não expõe dados protegidos por sigilo (como payloads brutos de integração).
Toda interação com o assistente é auditada para garantir a conformidade com as políticas de segurança da informação.
